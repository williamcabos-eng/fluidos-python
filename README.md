# Fluidos en Python

Programas y ejercicios de **Sistemas de fluidos (GITI)** que se ejecutan en el navegador, sin instalar Python.

Abrir: https://williamcabos-eng.github.io/fluidos-python/

Funciona en ordenador (Chrome, Edge, Firefox, Safari) y en el móvil. La primera vez descarga unos 20 MB.
Python se ejecuta con [Pyodide](https://pyodide.org) (numpy, scipy, matplotlib).
